# tools
Shared Claude Code configuration (global CLAUDE.md, skills, hook and statusline scripts, settings) that the dotfiles `claude` feature installs into `~/.claude`. `README.md` has the file tree; keep it in sync when adding, moving or removing files.

## No company-specific information
This repo is public and personal, and its config is installed on and edited from work machines. Never commit anything that identifies or describes an employer or its systems: company, team or product names, internal hostnames, domains, URLs or IPs, internal repo or org names, ticket IDs, Slack channels, usernames other than the owner's, or details of internal tooling. This covers instructions, skills, scripts, settings (e.g. permission rules naming internal hosts or tools), tests and fixtures, docs, commit messages, branch names and PR text. Write instructions and skills generically, so they apply to any repo or company. Keep work-specific config in a separate private tools repo listed in the dotfiles `DOTFILES_TOOLS` setting, which the `claude` feature installs alongside this one. If a request would need such details here, say so and suggest that instead. Before committing, check the diff for anything that came from the work environment (paths, hostnames, env vars, pasted output or session transcripts).
