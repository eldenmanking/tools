# tools
Shared Claude Code configuration (global CLAUDE.md, skills, hook and statusline scripts, settings) that the dotfiles `claude` feature installs into `~/.claude`. `README.md` has the file tree; keep it in sync when adding, moving or removing files.

## No company-specific information
This repo is public and edited from work machines. Never commit company, team or product names, internal hostnames, URLs, repo or org names, or ticket IDs, including in commit messages, branch names and PR text. Keep such details in a private tools repo listed in the dotfiles `DOTFILES_TOOLS` instead.
